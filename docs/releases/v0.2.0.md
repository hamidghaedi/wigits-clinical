## Changes

Laboratory QC consumes completed BAMTOOLS output events and complete laboratory
manifest membership. Once every required DNA library is ready, it can generate
one run-level report without waiting for variant/SV/CN analysis. The selected
coverage producer is32-thread CPU Parabricks4.6.0-1, with initial RAM derived
from measured BAMTOOLS depth and BAM size. Existing Picard insert metrics and
QC-only fastp products are reusable; reporting retains the approved Phase1
style and one summary row per manifest library. Missing demultiplexing data
remain disclosed rather than becoming a new launch gate. Event configuration
and queue enrollment remain explicit package inputs; source consolidation alone
does not enroll an existing run. See [laboratory QC](../LABORATORY_QC.md).

RNA input-v5 uses the actual task inputs for STAR, sorting, duplicate marking
and ISOFOX. WGS-only resource configs omit these RNA selectors. DNA input-v4
lane/sample sizing and the RNA optical-comparison correction remain as before.
New recovery packages can explicitly select RNA-only sizing without replacing
completed DNA requests. See [RNA resource rules](../RNA_RESOURCE_SIZING.md).

The upstream bindings remain Oncoanalyser3.0.0, installed source
3.0.0-qlmp.2.2 and HMF GRCh38 resources3.0.0--8. Native SAGE remains the default
caller. Existing source-value/reporting semantics, scientific holds and optional
DeepSomatic/BAM/QC-renderer route selection remain intact. CH/neo extension
branches are outside this consolidation.

## Publication and execution

The repository version is0.2.0. A reviewed main merge and immutable v0.2.0 tag
establish the release; the version file by itself is not a publication receipt.
Do not move existing component tags or rewrite issued runtime packages.

The maintained launcher still has Frontenac site bindings. Fir needs its own
explicit account/module/reference/container/path configuration and a target
runtime canary before new owner-operated analysis packages are issued. This
consolidation changes neither existing jobs nor their frozen code or resources.
